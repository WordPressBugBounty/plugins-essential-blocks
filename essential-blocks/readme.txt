== External services ==

Essential Blocks connects to the third-party services below. Nothing is sent to a service until the related block, feature or option is used, unless stated otherwise.

**Templately (app.templately.com)** – by WPDeveloper, the makers of Essential Blocks.
Used to list ready-made templates in the Templates tab of the Essential Blocks dashboard. A request is sent when you open that tab. Only the template query and your site's standard WordPress request headers (including the site URL) are sent.
[Terms](https://wpdeveloper.com/terms-and-conditions) · [Privacy Policy](https://templately.com/privacy-policy)

**WPInsight usage tracking (send.wpinsight.com)** – by WPDeveloper.
Only if you opt in (admin notice or Quick Setup checkbox). Sends your site URL and name, WordPress/PHP versions, language, server software, active and inactive plugins and theme, Essential Blocks block usage counts and the admin email address. Sent once on opt-in, and again on plugin deactivation if you opted in.
[Terms](https://wpdeveloper.com/terms-and-conditions) · [Privacy Policy](https://wpdeveloper.com/privacy-policy)

**OpenAI (api.openai.com)**
Used by the AI writing and image features only after you add your own OpenAI API key. Your prompt, any selected text or image, and your API key are sent when you run an AI action.
[Terms of Use](https://openai.com/policies/terms-of-use) · [Privacy Policy](https://openai.com/policies/privacy-policy)

**Openverse (api.openverse.org)** – run by WordPress.org.
Used by the Openverse block. Registering for an API key sends the name and email address you enter; searching sends your search terms; inserting an image downloads it from its source.
[Terms of Service](https://docs.openverse.org/terms_of_service.html) · [Privacy Policy](https://wordpress.org/about/privacy/)

**OpenSea (api.opensea.io)**
Used by the NFT Gallery block when you add an OpenSea API key. The collection slug or wallet address and your API key are sent when the block is edited or displayed.
[Terms of Service](https://opensea.io/tos) · [Privacy Policy](https://opensea.io/privacy)

**Instagram Graph API (graph.instagram.com)** – by Meta.
Used by the Instagram Feed block to load posts with the access token you provide, in the editor and on the front end (cached).
[Terms of Use](https://help.instagram.com/581066165581870) · [Privacy Policy](https://privacycenter.instagram.com/policy)

**Facebook Graph API (graph.facebook.com)** – by Meta.
Used by the Facebook Feed block to load page posts with the page ID and access token you provide. Once a token is saved, its validity is checked periodically in the admin.
[Platform Terms](https://developers.facebook.com/terms) · [Privacy Policy](https://www.facebook.com/privacy/policy/)

**Google Maps (maps.googleapis.com, maps.google.com)** – by Google.
Used by the Google Map block with the API key you provide. The Maps script and marker icons are loaded in the editor and on pages with a map, which sends the visitor's IP address to Google. Saving a key sends it to Google once to validate it.
[Terms](https://cloud.google.com/maps-platform/terms) · [Privacy Policy](https://policies.google.com/privacy)

**Google Fonts (fonts.googleapis.com, fonts.gstatic.com)** – by Google.
When the Google Fonts option is on (it can be turned off in Essential Blocks > Settings or Quick Setup) and a block uses a Google font, the font is loaded from Google in the editor and on the front end, which sends the visitor's IP address to Google.
[Terms](https://policies.google.com/terms) · [Privacy FAQ](https://developers.google.com/fonts/faq/privacy)

**YouTube (i.ytimg.com, youtube.com)** – by Google.
The Advanced Video block loads the thumbnail and player of a YouTube video you add, on the front end.
[Terms](https://www.youtube.com/t/terms) · [Privacy Policy](https://policies.google.com/privacy)

**Video providers (Vimeo, Dailymotion, SoundCloud, Wistia, Twitch, Facebook and others)**
When you add a video or audio URL from one of these providers to the Advanced Video block, that provider's player script and media are loaded from the provider in the editor and on the front end. The visitor's browser connects directly to the provider; see the provider's own terms and privacy policy (e.g. [Vimeo Terms](https://vimeo.com/terms) · [Vimeo Privacy](https://vimeo.com/privacy)).

**Remote SVG icons**
If an icon in a block is set to an SVG file URL on another site, the server downloads that file when rendering the page and caches it for 6 hours. Only a standard request to the URL you entered is made.

== Installation ==

**Note:** Since Essential Blocks is a Gutenberg library, you must activate Gutenberg editor to use it.

1. Go to your WordPress Dashboard and navigate to wp-admin -> Plugins -> Add New. Search for **Essential Blocks for Gutenberg**. Then simply click on the **Install Now** button.
2. Now click on **Activate** button to activate the plugin.
3. That’s it. You can access all blocks easily from Gutenberg editor.

Or,

1. You can download the plugin by clicking the **Download** button from **[Essential Blocks for Gutenberg](https://wordpress.org/plugins/essential-blocks/)**
2. Then go to wp-admin -> Plugins -> Add New and click on the **Upload Plugin**.
3. The plugin will be instantly installed & activated on your website.
For more detailed instructions, visit [Essential Blocks Installation Guideline](https://essential-blocks.com/docs/how-to-install-essential-blocks/). Also, check out a quick video tutorial from [Essential Blocks YouTube](https://www.youtube.com/playlist?list=PLWHp1xKHCfxAk6IzUeT_jvBDjiPghKJbe).

== Frequently Asked Questions ==

= How to insert blocks of Essential Blocks in your page or post? =
Install and activate Essential Blocks for Gutenberg on your website. Create a new page and click the ‘+’ sign, and you will find all the creative Gutenberg blocks there. Now click on the block you want to insert in your page and create amazing pages.

= Is there any limit creating AI-generated content and images with Essential Blocks? =
Essential Blocks allows you to create as many AI images and text as you want. And the feature is entirely free. All you have to do is integrate ChatGPT Pro with the plugin to use all of the AI features.

= How to save a block as a reusable block? =
You can save any block from Essential Blocks for Gutenberg as a reusable block easily. Click on any block you want to save as reusable, then click on the ‘Add to reusable blocks,’ and instantly, that block will be converted into a reusable block.

= What themes do Essential Blocks For Gutenberg support? =
Essential Blocks for Gutenberg has no theme dependency. This Gutenberg blocks plugin is compatible with any updated WordPress theme.

= Will Essential Blocks slow down my website speed? =
No, Essential Blocks will not slow down your website. This Gutenberg blocks plugin brings you the outstanding facility of complete modular control over the activation of each block. We have also used optimized codes for this plugin, which helps to load only the resources that are currently used.

= I do not know how to code. Can I still use Essential Blocks? =
Yes, you can still use Essential Blocks. These Gutenberg blocks are created in such a way that you can use and customize them without code.

= What other page builders can I use with this plugin? =
You can only use Essential Blocks with the Gutenberg editor. It does not support any other website builder or editor.

= Is Essential Blocks Responsive for Smaller Devices? =
Also, the Gutenberg blocks available with Essential Blocks plugin are 100% responsive and have cross-browser compatibility. So it is responsive on smaller devices as well.

= What is the best way to check for plugin conflicts on my website? =
Uninstall all plugins on your website except Essential Blocks for Gutenberg. Then check if any conflict is still occurring or not. If you encounter conflicts, then contact our support team.

= How to apply custom CSS to my blocks? =
If you want to apply custom CSS with Essential Blocks for Gutenberg, then click on the specific block you want to add CSS code to. Then navigate to the ‘Advanced’ tab and add your custom CSS code. You have to create a class first and then add your custom CSS.

= How can I get ready templates for Essential Blocks? =
If you want to skip customizing each essential block on your own, you can use ready templates to create stunning blocks. You will receive access to elegant and sleek, ready templates for Essential Blocks and Gutenberg with the Templately plugin.

= Can I get ready Gutenberg patterns from Essential Blocks? =
Yes, Essential Blocks provides you with a ready, professionally designed Gutenberg pattern.

= Does Essential Blocks have any plugin dependencies? =
You only need the Gutenberg block editor to use Essential Blocks plugin on your WordPress website. Then you can use Essential Blocks and create stunning pages.

= Does Essential Blocks provide any WooCommerce blocks for Gutenberg? =
Yes, you can effortlessly create stunning WooCommerce stores and display your products using Woo blocks from Essential Blocks. More blocks are coming soon.

= What should I do to use an earlier version of Essential Blocks? =
If you found the recent version of Essential Blocks isn’t working or conflicting with other plugins, then you can use earlier versions of the plugin.

= The Advanced Navigation hamburger menu doesn't open when a caching or optimization plugin is active. What should I do? =
Essential Blocks marks WordPress core's Interactivity API scripts so that WP Rocket, LiteSpeed Cache and Cloudflare Rocket Loader skip them. If you use "Combine JavaScript" or an aggressive "Delay JavaScript execution" mode that ignores these markers, add `wp-importmap` and `/wp-includes/js/dist/script-modules/` to that plugin's JavaScript exclusion list, then clear all caches.
